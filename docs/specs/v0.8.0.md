## 0. (머지 완료) 우측 패널 개요 중심 전환

개요 기본 표시, 백링크 패널 제거. 백링크 API·그래프 inlink는 유지.

## A. Quick Switcher — ⌘K (`QuickSwitcher.tsx`)

- 전역 ⌘K로 중앙 모달 오픈 (Esc 닫기)
- **빈 입력**: 최근 연 파일 목록 (네비게이션 히스토리 기반, 없으면 mtime 순)
- **입력 시**: ① 파일명/제목 퍼지 매치(클라이언트, filesFlat 캐시) ② FTS 본문 매치(기존 `/api/search`, 250ms 디바운스) — 두 섹션으로 구분 표시, 스니펫 포함
- ↑↓ 이동, Enter 열기(본문 매치는 해당 라인으로 점프), 디자인 토큰 기반 모달
- 사이드바 검색창과 역할 분리: 사이드바=필터·연산자 검색 유지, ⌘K=점프 특화

## B. 오늘의 변경 피드 (`ActivityFeed.tsx` + `GET /api/activity`)

- **백엔드**: `GET /api/activity?days=14` → mtime 역순 항목 `{path, name, title, mtime, created_same_day}` (인덱스 files 테이블 + st_birthtime; birthtime 미지원 시 false)
- **프론트**: 문서 미선택 상태(=실행 직후)의 `.main`을 placeholder 대신 피드로:
  - 최상단 "이어서 읽기" 카드 (D의 마지막 세션 문서, 있을 때만)
  - "오늘 / 어제 / 이번 주 / 그 이전" 날짜 그룹, 항목에 신규(`created_same_day`) 배지
  - 클릭 → 문서 열기. 빈 vault면 기존 placeholder
- 사이드바 브랜드(mdedit) 클릭 → 피드로 복귀 (홈 역할)

## C. 뒤로/앞으로 히스토리

- App 수준 히스토리 스택: 문서 전환 시 push, ⌘[ 뒤로 / ⌘] 앞으로
- 히스토리 복귀 시 해당 문서의 저장된 스크롤 위치(D)로 복원
- 최근 목록(A의 빈 입력 상태)과 스토리지 공유 (`mdedit:recent`)

## D. 읽던 위치·세션 복원

- `.main` 스크롤 위치를 파일별 localStorage에 debounce 저장 (`mdedit:scroll:<path>`)
- 문서 열 때: `scrollToLine` 지정(검색 점프)이 우선, 없으면 저장 위치 복원, 둘 다 없으면 0
- 마지막 열람 문서를 `mdedit:last-doc`에 저장 → B의 "이어서 읽기" 카드 소스
- Reader 렌더 완료 시 `mdedit:rendered` 이벤트 발행 → App이 복원 타이밍 확보
