# v0.6.0 디자인 업그레이드 스펙 — "세련된 리더"

> 방향: iA Writer / Bear 계열. 타이포그래피 중심, 여백·행간 정돈, 절제된 색.
> 레이아웃 구조(2컬럼 그리드, 패널)는 유지하고 표면 품질만 끌어올린다.

## 1. 디자인 토큰 (`:root` CSS 변수로 일원화)

### 타이포그래피
| 토큰 | 값 | 비고 |
|---|---|---|
| 본문 크기 | 17px (현 16px) | 읽기 거리 기준 최적 |
| 본문 행간 | 1.78 (현 1.6대) | 한글 가독 핵심 |
| 본문 폭 | 측정 38rem(~646px) | 현 720px는 한 줄이 김 |
| 문단 간격 | 0.9em | 행간과 분리 |
| 자간 | -0.011em (본문), -0.02em (제목) | Pretendard 최적치 |
| 제목 스케일 | h1 1.65rem / h2 1.3rem / h3 1.1rem | 차분한 위계 |
| 제목 위 여백 | 2.2em (h2), 1.8em (h3) | 섹션 호흡 |

### 색 (라이트)
| 토큰 | 값 | 용도 |
|---|---|---|
| `--paper` | `#FBFBFA` | 본문 배경 (순백 대신 종이톤) |
| `--ink` | `#1C1E21` | 본문 텍스트 (순흑 대신 웜 블랙) |
| `--ink-soft` | `#6E7178` | 메타·보조 |
| `--accent` | `#2E66D0` | 링크·포커스 (현 #1D8BFF보다 차분) |
| `--surface` | `#F4F4F2` | 사이드바·코드 배경 |
| `--line` | `#E8E8E5` | 경계선 |

### 색 (다크) — 동일 토큰 오버라이드
`--paper #15171A`, `--ink #E8EAED`, `--accent #7AA5F0`, `--surface #1C1F24`, `--line #2A2D33`

## 2. 컴포넌트 폴리시

- **사이드바**: 브랜드 글자 축소·감량, 행 hover를 배경 대신 미세한 들여쓰기+색 변화로, 선택 행은 좌측 2px 액센트 바. 파일명/메타 대비 정돈
- **Reader 본문**: 링크 밑줄 `text-underline-offset: 3px` + 톤 다운, `::selection` 액센트 연출, blockquote는 좌측 보더+이탤릭 제거+종이톤 배경, hr은 중앙 정렬 짧은 선, 테이블 라인 경량화
- **코드**: 인라인 코드 배경 `--surface` + 1px 보더, 블록은 라운드 8px + 헤더 여백
- **frontmatter 카드**: 보더리스 → 1px `--line` + 라운드, 키 컬러 `--ink-soft`
- **검색/리스트**: 스니펫 mark 톤 정리(형광 → 은은한 액센트 배경), 고정 섹션 라벨 기존 유지
- **전환**: 문서 로드 시 본문 80ms fade-in, hover 트랜지션 120ms — 과한 모션 금지
